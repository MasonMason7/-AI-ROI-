# MemberPilot AI

会员权益 ROI 与定价测算系统。项目源于此前的企业业务自动化测算实践，将“多源数据、复杂规则、金额计算、差异追溯、正确率校验”的方法迁移到互联网会员业务，帮助产品经理判断会员方案是否值得上线。

## 项目简介

会员产品常见问题不是“有没有权益”，而是“权益是否划算”。MemberPilot AI 以会员价格、目标用户、订单毛利、权益核销和续费率为输入，输出会员收入、权益成本、ROI、LTV、盈亏平衡续费率，并给出异常提醒、追溯解释和复盘建议。

## 为什么从业务自动化测算扩展到会员测算

此前的企业业务自动化测算项目解决的是复杂规则计算与结果校验；会员定价也存在类似结构：

- 基础对象信息 -> 用户分层
- 业务规则 -> 会员权益规则
- 金额调整项 -> 优惠券 / 免邮 / 折扣 / 服务成本
- 明细结果 -> 会员收入、成本、ROI 明细
- 差异追溯 -> 会员方案亏损原因追溯

因此，本项目不是重新发明一个场景，而是把原有能力抽象到“商业测算 + 决策复盘”中。

## 核心功能

- 会员方案选择：月卡、年卡、Plus、VIP 等样例方案
- 核心指标计算：会员收入、权益成本、会员毛利、ROI、LTV、盈亏平衡续费率
- 数据校验：检查 ROI 为负、权益成本过高、续费率低于盈亏平衡点等问题
- AI 追溯解释：用规则模板解释 ROI 偏差来源
- 方案对比：横向比较不同会员方案的价格、成本、利润和权益核销率
- 高级价值模型：计算价格敏感度、权益挤压损失、续费质量、会员价值分和模型置信度
- 产品决策层：输出上线建议、用户分层机会、A/B 实验计划和指标护栏
- 复盘报告：生成适合产品经理汇报的简短结论与下一步建议

## 系统架构

```text
React + Vite 前端
        |
        | HTTP
        v
FastAPI 后端
        |
        ├─ data_loader：读取 CSV 示例数据
        ├─ rule_engine：解析会员价格与权益规则
        ├─ calculator：计算 ROI、LTV、成本和利润
        ├─ advanced_model：计算会员价值分、价格敏感度与权益挤压损失
        ├─ validator：检查异常和正确率风险
        ├─ trace_analyzer：解释偏差来源
        ├─ ai_advisor：生成规则模板式 AI 建议
        ├─ product_strategy：生成上线决策、分层机会、实验计划和指标护栏
        └─ report_generator：生成复盘报告
```

## 业务流程

```text
选择会员方案
  -> 读取会员、订单、权益核销样例数据
  -> 解析价格和权益规则
  -> 计算收入、成本、ROI、LTV
  -> 校验异常与风险
  -> 追溯关键影响因素
  -> 形成上线建议、实验设计和指标护栏
  -> 输出方案对比和复盘报告
```

## 核心指标

- 会员收入 = 会员价格 x 目标会员数
- 权益成本 = 权益核销成本 + 服务成本
- 会员毛利 = 会员收入 + 增量订单毛利 - 权益成本
- ROI = 会员毛利 / 权益成本
- LTV = 单会员月均利润 x 预估生命周期
- 盈亏平衡续费率 = 权益成本 / 可覆盖成本的收入与毛利
- 权益核销率 = 已使用权益数 / 已发放权益数
- 价格敏感度指数 = 会员价格 / 加权用户 ARPU / 会员周期
- 权益挤压损失 = 权益成本 x 核销率 x 动态挤压系数
- 会员净序列价值 = 会员毛利 - 权益挤压损失 + 续费质量增益

## 产品经理视角亮点

- 不只做结果展示，而是把数据导入、脚本计算、异常追溯、上线决策串成完整闭环
- 从“ROI 是否为正”进一步拆到“哪个用户分层值得先做、哪个权益造成成本挤压、哪个方案适合灰度”
- 将测算结果转化为 A/B 实验设计，包括假设、实验组、对照组、主指标和护栏指标
- 适合展示产品经理对业务公式、数据质量、策略实验和跨团队落地的理解

# AI 追溯与正确率校验

## 设计目标

MemberPilot AI 的 AI 能力不追求“直接给结论”，而是辅助产品经理理解结论从哪里来、哪里可能错、下一步应该验证什么。

## 追溯机制

系统会根据以下因素解释 ROI 偏差：

- ROI 是否低于 1
- 权益核销率是否过高
- 预估续费率是否低于盈亏平衡续费率
- 单会员权益成本是否高于会员价格
- 方案是否依赖增量订单毛利来覆盖成本

## 异常解释

示例：

```text
权益核销率偏高，说明优惠券或免邮权益是主要成本驱动项，建议设置使用门槛或按用户分层发放。
```

## 正确率校验

系统会检查：

- 会员价格是否为正
- 目标会员数是否为正
- ROI 是否为负
- 权益核销率是否过高
- 权益成本是否超过会员收入的合理比例
- 预估续费率是否低于盈亏平衡续费率

## 当前 AI 实现边界

当前版本不调用真实大模型，而是使用规则模板生成自然语言建议。这样做的原因是：

- 展示核心产品逻辑，不依赖外部 API
- 保证结果可复现
- 方便面试官在本地直接运行

未来可接入真实 LLM，用于生成更自然的复盘报告和 What-if 分析。

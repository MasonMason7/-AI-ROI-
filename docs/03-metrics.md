# 指标体系

## 会员收入

```text
会员收入 = 会员价格 x 目标会员数
```

用于衡量会员费本身带来的直接收入。

## 权益成本

```text
权益成本 = 权益核销成本 + 服务成本
权益核销成本 = 已使用权益数 x 单次权益成本
```

用于衡量优惠券、免邮、折扣、专属服务等权益造成的成本。

## 增量 GMV

```text
增量 GMV = (会员平均订单金额 - 非会员平均订单金额) x 目标会员数 x 会员周期
```

用于估算会员身份带来的额外交易规模。

## 会员毛利

```text
会员毛利 = 会员收入 + 增量订单毛利 - 权益成本
```

这是判断方案是否健康的核心结果。

## ROI

```text
ROI = 会员毛利 / 权益成本
```

用于判断权益投入是否产生足够收益。

## LTV

```text
LTV = 单会员月均利润 x 预估生命周期
```

用于评估单个会员在生命周期内的长期价值。

## 续费率

当前模型使用 `expected_renewal_rate` 作为预估续费率，并与盈亏平衡续费率比较。

## 权益核销率

```text
权益核销率 = 已使用权益数 / 已发放权益数
```

核销率过高可能意味着权益成本压力变大；核销率过低则可能说明权益吸引力不足。

## 盈亏平衡点

```text
盈亏平衡续费率 = 权益成本 / 可覆盖成本的收入与增量毛利
```

如果预估续费率低于盈亏平衡续费率，方案存在长期亏损风险。

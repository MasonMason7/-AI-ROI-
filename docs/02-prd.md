# PRD：MemberPilot AI

## 背景

会员产品在电商、本地生活、内容平台中非常常见，但会员方案设计往往依赖人工表格测算。产品经理需要同时考虑价格、权益成本、用户规模、订单毛利、续费率和权益核销率，计算链路长且容易出错。

## 目标用户

- 会员产品经理
- 增长产品经理
- 运营策略同学
- 商业化分析同学

## 核心痛点

- 定价方案多，人工比较效率低
- 权益成本分散，容易被低估
- ROI、LTV、续费率等指标口径不统一
- 结果不好时，很难快速解释亏损原因
- 复盘材料需要手动整理

## 用户流程

```text
选择会员方案 -> 查看核心指标 -> 检查异常提醒 -> 阅读追溯解释 -> 对比其他方案 -> 输出复盘结论
```

## 功能模块

- 方案选择：切换不同会员方案
- 指标测算：计算收入、成本、利润、ROI、LTV
- 异常校验：发现成本过高、ROI 为负、续费率不足等风险
- 追溯解释：说明影响 ROI 的关键因素
- AI 建议：生成下一步优化建议
- 方案对比：表格横向比较不同方案
- 复盘报告：输出简短业务结论

## 边界范围

MVP 不做用户登录、数据库、真实支付数据接入、真实大模型调用和线上部署。当前使用 CSV 样例数据，重点展示产品思路和计算闭环。

## 风险

- 样例数据不能代表真实业务结果
- ROI 模型是简化版本，需要真实业务校准
- AI 建议为规则模板生成，不能替代最终商业决策
- 会员权益成本在真实业务中可能受财务口径影响
